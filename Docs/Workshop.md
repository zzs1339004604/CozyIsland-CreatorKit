# 安装、管理和发布模组

适用于带「模组」菜单的《舒舒服服小岛时光》（Cozy Island）。如果是第一次安装或制作模组，先从 [Cozy Island Modding 首页](../README.md) 开始。

## 本地文件和 Steam 订阅

| 位置 | 用途 |
| --- | --- |
| 下载的仓库中的 `MyMods/<作品名>` 或自己的源码目录 | 保存源码、作品信息和资源。这里的改动需要复制到游戏里才能测试。 |
| 游戏的 `Mods/<作品目录>` | 放本地安装副本。每个作品目录的第一层有一个 `mod.json`。 |
| Steam 管理的创意工坊目录 | Steam 下载和更新你订阅的作品。需要测试自己的改动时，请用本地副本。 |

在游戏的 **模组 → 模组创作** 中点击 **打开作品文件夹**。没选中作品时打开 `Mods`，选中作品时打开它的目录。把新作品放在 `Mods` 下，与已有作品并排。切回游戏或重新打开模组菜单会检查本地文件。

同一作品的本地版和工坊版可以同时保留。在菜单启用其中一份时，游戏会停用使用同一 UUID 的其他副本。详情里可以查看作者、版本和安装位置。订阅回测时，请确认选择的是工坊副本，再完全退出并重开游戏。如果旧设置里同一作品有多个副本同时启用，请在进岛前选定一份。

## 账号设置

启用状态、加载顺序及本机工坊发布关联保存在游戏用户数据目录的 `mods-<SteamID>.json`，与 `Mods` 同级。Windows 默认的用户数据目录是 `%USERPROFILE%\AppData\LocalLow\LazyFish Studio\CozyIsland`。没有有效 Steam 会话时，游戏使用独立的 `mods-local.json`。上次写入的备份保存在对应的 `.json.bak` 文件。

启用状态按本地目录名或工坊数字 ID 记录。发布关联按 Steam 账号和作品的 UUID 保存。改目录名、换 Steam 账号或切换副本后，先在菜单重新选定作品并确认生效，再读取使用该作品的存档，以免缺失的物品被清理。依赖和重启规则见 [加载顺序与重启](Reloading.md)。

## 下载失败或无法进岛

已启用的作品如果还在下载，或有依赖、文件或加载错误，游戏会暂时阻止进入岛屿。先等待 Steam 完成下载，或按菜单提示修复问题并重启。主动停用作品后读档前，请先了解 [存档里的缺失物品会怎样处理](Save-Data.md#缺失内容与失败是不同情况)。

如果游戏因为模组无法正常启动，可以在 Steam 的 **属性 → 通用 → 启动选项** 填入 `--disable-mods` 再启动。这时可以管理模组。停用有问题的作品后退出游戏，清除启动选项再正常启动。恢复模式会保留原先的启用选择、顺序和发布关联，并暂停运行所有模组及进入岛屿。

## 发布和更新

发布前，在游戏里启用本地作品并试一遍。涉及物品、世界状态或多人游戏的作品，请另用测试岛验证保存后重开、停用和联机。 [创作验收方法](Native-Authoring.md#验收与证据)

从 **模组 → 模组创作** 修改作者信息时，**保存修改** 只更新选中的本地安装副本。把要保留的修改同步回源码目录。如果改用命令发布，请使用已经试过的那一份运行包。 [命令行校验与发布](../Tools/README.md#编译并验证运行包)

- 首次发布默认私密。更新时，如果没有勾选公开，作品会保留在 Steam 上原有的可见性。要把已公开的作品改为私密，可以使用发布命令显式设置。 [发布命令与可见性](../Tools/README.md#上传单个作品)
- 更新同一作品请使用原来的工坊数字 ID。换电脑或丢失本机关联时，可以在游戏里填回原 ID。游戏会核对作品是否属于当前 Steam 账号和本游戏，作者还应核对标题及链接。
- 上传时，游戏只把作品运行需要的文件复制到上传目录，源码、编译引用及缓存会被排除。封面需小于 1 MiB，运行包最多 256 MiB、4,096 个文件。 [清单和包限制](Manifest.md#文件和发布边界)
- 上传完成后，请订阅并试用 Steam 下载的那份。如果上传超时，先检查工坊页面、仍在运行的进程及日志，再使用原工坊数字 ID 重试。 [上传结果和日志](../Tools/README.md#上传单个作品)
